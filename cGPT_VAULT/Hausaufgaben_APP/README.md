# Dr. DirKInstitute LernTutor

Eine deploybare Next.js-LernApp fuer Klassen 5 bis 13 mit:

- Schulart
- Fachauswahl aus JSON-Konfiguration
- Lernmodi
- Tutor-Hinweisen
- Druck-/PDF-Ausgabe

## Lokal starten

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Empfohlen ueber GitHub und Vercel.
